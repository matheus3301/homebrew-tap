# 🍺 Homebrew Tap

Homebrew formulae for [@matheus3301](https://github.com/matheus3301) projects.

## Installation

```bash
brew tap matheus3301/tap
brew install loopforge
```

Or in a single command:

```bash
brew install matheus3301/tap/loopforge
```

## Available Formulae

| Formula | Description | Version |
|---------|-------------|---------|
| [loopforge](https://github.com/matheus3301/loopforge) | Autonomous coding loops CLI | 0.1.1 |

## Updating

```bash
brew update
brew upgrade loopforge
```
